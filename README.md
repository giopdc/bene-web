# Bene — web

- Text: each element has `data-es` and `data-en` attributes; edit both.
- Contact: see the "Contacto" section. Vinted/Wallapop show "Próximamente" until their links are added.
- Publishing: every push to `main` is deployed by Cloudflare to https://bene-web.ciaterbox.workers.dev
